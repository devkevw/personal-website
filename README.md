# My Personal Website

Welcome to my [website](https://kevinjwang.xyz/)! This repository contains the code for my site, which showcases some of the things I've been up to over the years: my career, writing, travels, and a few early coding projects. Built from scratch using HTML, CSS, and JavaScript. I hope you enjoy exploring it!

## Features

- Career and education timeline, with a little more about me.
- Writing, including pieces published on Medium.
- Travel photo albums with regional filters and a photo viewer.
- Rotating photo carousels, a typing introduction, and interactive headings.
- Light and dark themes, with a responsive layout for phones, tablets, and desktops.

The original version is preserved in the `v1` Git tag.

For local setup, content editing, testing, and deployment notes, see the [development guide](docs/DEVELOPMENT.md).

Original design inspired by Seán Halpin.
